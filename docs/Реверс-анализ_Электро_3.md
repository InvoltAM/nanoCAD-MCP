| Что | Как получить | Проверено |

| DI-контейнер | статическое свойство `Nanosoft.Utils.CwPlatform.Container` (тип `Nanosoft.Platform.Platform.IContainer`, сборка Nanosoft.Platform) | ✅ |

## Создание группы (проверенный сценарий M2)

1. Найти щит: `net.Nodes` → узел типа `Nanosoft.Electrica.ElBoard`.
2. Эталон = `board.OutFiders[0]`; скопировать в новый `DbElFiderKitItem`:
   - `FiderType` (FiderTypeEnum), `PoleCount` (PhaseCountEnum из fider.PhaseCount), `FiderFilling` (ElFiderFillingEnum);
   - `SafeAutomat` = `refFider.SafeAutomat.Db` (живой `DbElAutomat` с DbId → привязка к БД оборудования);
   - `Text` = имя группы.
3. `craetor.CreateNewFider(kit, board)` → фидер появляется в `board.OutFiders` и в панели «Сеть проекта».
4. `net.SaveObject(board, true, paperId)`.

## Структура объектов (дампы реальных узлов)

- `ElBoard`: OutFiders (List<ICaeFider>), InputFiders, ShellFilling, Db (DbElBoard, DbId), Label/Marking, маски имён групп (OutFiderMask `гр <№ фидера>`), MountingHeight, слой `ЭЛ_ШКАФЫ`.
- `ElFider` (base `CaeFider`): Name, GroupNumber, FiderType, PhaseCount, SafeAutomat (ElAutomat), методы `AddSafeAutomat(dbId)`, `AddUzo(dbId)`, `AddSafeFuse(dbId)` — наполнение по ID записи БД; расчётные поля Ikz2P/Ikz3P, DeltaU, PcalcDp, RepCableMark/Section/Inom.
- `ElAutomat` (base ElFiderGadget): Db (DbElAutomat: NominalCur, DbPoleCount `PC_3P (4)`, PhaseCount `THREE (2)`, VoltageType `Voltage380220 (1)`, CurrentScale, AutomatCharReleaseType, ActiveResistance/InductiveResistance), InstCurrent, ReleaseCurrent, PoleCount, FiderGadgetCode `QF`.
- `ElSocket` (base ElConsumer): Pnom, CosPhi, LoadingAssignment, DbId → DbElSocket.
- Enum'ы читаются числом: `Convert.ToInt64(enum)` — см. дампы `DumpNode`.

## Слой данных БД оборудования

`Nanosoft.ObjectLib.ESN.Db.DbImpl.*`: DbElAutomat, DbElBoard, DbElFider, DbElFiderKitItem, DbElSocket, DbElUzo, DbElSwitch… `DbKitItem` базовый (Nanosoft.Data). DbId — целочисленный ключ записи БД (SqlCe/SQLite, Nanosoft.Studio.DataBase).

## Эндпоинты плагина (CadEngine.Plugin, localhost:5080)

- `GET /api/electro/model/discover` — акцессоры контейнера/сети
- `GET /api/electro/model/resolve/{type}` — резолв компонента из DI
- `GET /api/electro/model/net` — сводка модели (число узлов, типы, щиты)
- `GET /api/electro/model/boards` — щиты с наполнением
- `GET /api/electro/model/nodes/{type}` — узлы по фильтру типа
- `GET /api/electro/model/node/{acId}` — полный дамп свойств узла
- `GET /api/electro/model/group/create/{boardAcId}` — создать тестовую группу (PoC)
